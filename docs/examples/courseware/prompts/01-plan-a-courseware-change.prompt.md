Inspect the current courseware source and build configuration. Map the content files, reader interface, authentication and access checks, and deployment process. Propose one small improvement to chapter navigation. Identify the source files it would affect, how to preview it, and how to verify existing navigation and access behavior. Do not edit generated data directly, change authentication rules, deploy, or expose private repository links. Save a plan before implementing anything.
