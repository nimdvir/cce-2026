---
description: "02 review semester changes"
---

Compare the older syllabus with the instructor-designated current version. Separate formatting changes from content changes. List changes to dates, policies, grading components, weights, resources, and meeting information. Check each weight as well as its total. Do not assume a newer file is correct just because its filename or modification date is newer. Flag calendar-dependent decisions instead of inventing dates. Produce a review report without changing either source.
