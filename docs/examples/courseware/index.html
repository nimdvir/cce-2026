The task

Bring chapters, guided activities, labs, and navigation into one learning environment for BITM 330. This is a bigger project, and it is still going. Agents help with the content and the software. I design the learning sequence and review every change.

Starting materials

  • Chapter and lab source files, figures, learning activities, and a course outline.
  • A reader interface with chapter and section navigation.
  • Account and course-access requirements.
  • A repeatable build and deployment process.

How the project is assembled

  1. Organize the learning content

    Draft and review the course materials in the working folders. The current generator supports chapter HTML and Markdown sources, selected through chapter metadata. The content is kept separate from how the reader looks.

  2. Bring reviewed sources into version control

    GitHub stores the project source and change history. Review proposed changes before they become part of a published version. The courseware repository is not linked from this demonstration.

  3. Assemble the reader data and interface

    Build scripts assemble the source content and metadata for the reader. The current interface uses React and TypeScript, with Vite for the application build. Generated content is rebuilt from its sources.

  4. Connect account access

    Supabase supports authentication and course-access data. The application checks access separately from how it displays a chapter. Account controls require their own verification when the interface changes.

  5. Build, preview, and deploy

    The Vercel configuration runs the full build and serves its output at the custom domain. The configuration also includes a protected-content API route. Review a preview and check key reading and access paths before promoting a change.

  6. Make small, reviewable improvements

    Give the agent one small task, the files it needs, what should happen, and how to check it. Review the change, then do the next one. The whole platform was built this way.
