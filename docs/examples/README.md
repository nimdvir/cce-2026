# CCE 2026 examples

Open `index.html` for a short index, or `../examples.html` for the Examples page of the website.

1. [From outline to conference website](site/index.html)
2. [From Word syllabus to HTML](syllabus/index.html)
3. [One dataset, two AI analyses](data-analysis/index.html)
4. [Building interactive courseware](courseware/index.html)

Each project includes its saved prompts and images. The data-analysis folder holds the two finished reports with aggregate results only. The raw course responses, the analysis scripts, and the original Word and PDF syllabus files are not published.

The `index.html` pages in this folder are written by hand. `docs/build.py` does not generate them, but it does check their links.
